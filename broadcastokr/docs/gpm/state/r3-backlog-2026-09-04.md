## Readiness Decision

**PROCEED.** The two product inputs the instructions asked for were taken 2026-09-04
(Yannick, in conversation):

- **Tier map (v1):** `starter` = manual KRs and check-ins only; `pro` = + live KRs (bridge
  and agent), templates/materialisation, agents, history and reports; `enterprise` = + the
  Mediagenix sharing channel (fleet board) and, later, Insights AI. SSO and audit are how a
  cloud instance runs, not features, and stay on for every tier. Caps — channels, seats
  (owner/manager; members are viewers and free), agents — are numbers in the licence,
  independent of the tier; unset = unlimited.
- **Licence carrier:** plain values in the provisioned env (`BRIDGE_TIER`,
  `BRIDGE_CAP_CHANNELS`, `BRIDGE_CAP_SEATS`, `BRIDGE_CAP_AGENTS`), written by
  `provision-instance.mjs --tier … --cap-*`. Instances run in Mediagenix's cloud, so the env
  is operator-controlled. Rejected for now: a signed licence minted by the cockpit — needed
  only if instances ever run outside that control; **recorded as a residual** (R4/R2).
- Desktop and the cockpit are unrestricted (enterprise): the desktop is single-user, the
  cockpit is Mediagenix's own. A client instance without `BRIDGE_TIER` runs as enterprise and
  says so at startup (an unlicensed instance must not be a bricked one).

Clarity 3, feasibility 3, completeness 3 → 9/9.
